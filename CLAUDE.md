# CLAUDE.md

forgewright is one TypeScript API for many git forges (GitHub and GitLab so far), typed from each forge's OpenAPI description. It's an unpublished prototype.

## Commands

- Before committing, run what CI runs: `npm run lint && npm run typecheck && npm test && npm run build && npm run check:browser`.
- `npm run all` is not the gate: it runs `fix` (which rewrites files) instead of `lint`, and skips `check:browser`.
- `npm run fix` applies ESLint and Prettier fixes.
- `npm run test:live` writes to a real GitHub repository (issues, PRs, merges). Run it only with the owner's go-ahead.

## Generated files

- `spec/*/openapi.json` and `src/services/*/openapi.ts` are generated by `npm run specs:update` from the pins and operation lists in `spec/<forge>/config.json` plus the overlays in `spec/<forge>/overlays/`. Change those inputs and regenerate; never edit the outputs. CI fails if they're out of date.
- `npm run specs:bump` moves the pins to the latest upstream versions.

## Gotchas

- [update-specs.yml](.github/workflows/update-specs.yml) runs every Monday and opens or updates a PR on this repo. Those PRs are opened with `GITHUB_TOKEN`, so CI doesn't run on them; the workflow runs the typecheck and tests itself and reports them in the PR body.
- `specs:update` fails on purpose when an overlay stops matching or a listed operation disappears upstream. That needs a person to look, not a workaround.
- `check:browser` bundles [src/index.ts](src/index.ts) for the browser, so don't import Node built-ins from library code.
